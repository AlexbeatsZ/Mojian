# Packed stroke samples: `pointsCoded` (v1)

A stroke stores either `points` (array of objects, unchanged legacy form) or `pointsCoded`
(string), never both. All Windows/Android/macOS readers since 0.7.36 accept both. Writers emit
`pointsCoded` for strokes they serialize when the points are eligible; untouched strokes keep their
original JSON. Background: `docs/design/ink-storage-format.md` (AndroidX Ink CodedNumericRun, ISF).

## Text

`"1:" + base64(bytes)` — standard RFC 4648 alphabet with `=` padding.

## Bytes

1. `count` — unsigned LEB128.
2. `optional` — unsigned LEB128 bit set of optional channels present (bit 0 = channel 2 below).
3. For each present channel in this order, `count` zigzag LEB128 int64 deltas; each channel starts
   from 0: `q[i] = q[i-1] + delta[i]`, `value = q / scale`.

| # | JSON name | scale (q = value × scale) | presence |
|---|---|---|---|
| 0 | `x` | 1000 (0.001 DIP) | always |
| 1 | `y` | 1000 | always |
| 2 | `pressure` | 10000 | optional |
| 3 | `elapsedMilliseconds` | 1 (integers only) | optional |
| 4 | `tiltX` | 100 (degrees) | optional |
| 5 | `tiltY` | 100 | optional |
| 6 | `tiltRadians` | 10000 | optional |
| 7 | `orientationRadians` | 10000 | optional |

Quantization: `q = s >= 0 ? floor(s + 0.5) : -floor(-s + 0.5)` with `s = value * scale` in IEEE
double. Zigzag: `(d << 1) ^ (d >> 63)`. Trailing bytes or truncated varints are errors.

## Eligibility

Pack only when every point is an object whose keys are all in the table, `x`/`y` are present,
each optional channel is present in every point or in none, values are finite numbers and
`elapsedMilliseconds` is integral. Otherwise keep `points` (e.g. per-point extension fields).
Decoders give absent channels each client's existing default. Quantization error is at most half
a quantum (0.5 µm-scale); `elapsedMilliseconds` is exact.

Golden vectors: `shared/fixtures/points-coded.json` (generated by an independent implementation).
