### 2026-10-19 fix(selection): 修复光标粘贴并支持动态 Ctrl 拖动复制

- 原因：原格式粘贴沿用源坐标加固定偏移，导致内容出现在旧位置；用户要求在选区拖动中随时按放 Ctrl，以松开鼠标时的状态确定是否留下原位副本。
- 改动：Windows/Android 以目标页面的插入光标定位原格式内容和系统图片，分别平移 X/Y 并保留相对几何及矢量变换；记录光标以跨越工具栏焦点变化。直接选区移动捕获起始快照，Ctrl 按键与指针事件共同驱动仅显示的原位预览，抬起时提交新身份副本并保留移动后选区；取消、页面切换和缩放不产生副本。Windows 的移动/复制共用一次 Undo。同步更新设计文档及回归用例。
- 验证：Windows Release 构建/发布成功，0 错误/0 警告；Android assembleDebug 成功（保留既有的系统栏 API 弃用警告）。测试与验收已按用户要求中止，最终源码未再运行测试、lint 或 UI/设备验收；新增及调整的回归用例未重跑。
- 交付：Windows 正常保存关闭后替换唯一 Release EXE 并重新启动；Android 当前 APK 已刷新，本轮未安装到平板。
