# 页面撤销与缩放

Last verified: 2026-11-25

修改撤销/重做、页面内容变更通知或离散缩放入口前阅读本文件。

## 撤销边界

- 当前页的书写、整笔擦除、混合内容移动/缩放/复制、删除、剪切/粘贴、文字编辑与格式、
  图片变换/裁剪/反色/层次、清空以及单页纸张/底纹/颜色/标题显示设置共用按时间排序的历史。
- 视图平移、缩放、选择/套索预览、焦点、全局明暗主题及默认新页偏好不进入页面历史。
  撤销内容时保留当前 viewport。A4 页数和无界纸张自动增长仍保持单调，不因撤销缩小。
- 一次橡皮接触（含压力临时橡皮）包含所有命中，一次选区拖动包含全部采样和内容层；
  一次混合删除/粘贴/清空/插入空间各是一条记录。没有实际变化不消费历史或清除重做。
- 新文档修改清空重做分支；页面重新绑定清空历史。打开已有页面后不能凭空撤销最后一笔旧墨。
  当前历史容量为最近 80 次编辑，历史不写入共享笔记文件，也不跨客户端同步。
- 清空和删除对象不能即时删除仍被撤销记录引用的图片/附件资源。资源回收需要独立的引用与保留策略。
  Windows 仍保留其既有单笔追加和擦除增量记录；复杂操作使用冻结内容快照。

## Android

`MainActivity.pageHistory` 是产品页面历史所有者，使用 `DocumentEditHistory<PageEditSnapshot>`。
工具栏、键盘和实体笔键的全部撤销/重做入口都调用 `undoPageEdit` / `redoPageEdit`。
`DryInkView` 的独立历史仅供不带页面宿主的画布使用；产品设置 `documentHistoryManaged=true`，
不再给每笔附加第二份独立历史，也不挂接旧的仅图片裁剪历史回调。

页面绑定后保存初始版本。Ink、Tag、Text、Object 各层的内容通知和单页设置修改经 `pageEdited`
进入同一条记录。快照按修改层复用未变字段：笔迹保存不可变 AndroidX `Stroke` 引用列表，
不遍历/序列化所有笔点；小对象复制，富文本保留独立 `SpannableString`，以 HTML 和几何比较实际变化，
忽略编辑器的选择/焦点 span。文本层清空必须发出内容通知，替换/恢复编辑器时禁止该通知。
快照另外保留 Tag/Text/Object 的原始 canonical 元数据；恢复文字时重置 codec 的原始文字缓存，
避免删除已保存后撤销丢失导入字段、来源图层和未识别属性。只编码变化的文字/标签，不编码笔点。

橡皮首次接触开始事务，抬笔/取消/工具切换结束；选择层在超出拖动阈值且首次变换前开始事务，
释放和父层接管取消都结束事务。已经发生的单指变换/擦除在取消后保留为一次可撤销编辑。
嵌套事务在最外层结束时才采样快照，不能每个 MOVE 都复制整页。对象变换的完成通知须先于事务结束。
混合粘贴、删除、清空和插入空间使用 `transaction`，插入空间同时移动文字。

恢复时抑制新历史，按变化的层恢复并经原保存队列标脏；不重建未变化的墨迹或文字。
自动主题映射允许重建显示笔迹，但不能记录为文档操作。释放旧页前清除历史和缓存版本，
避免历史持有整个上一页的 native ink/JSON 图。自动同步重载沿用已有页面重绑边界。

## Windows

`NoteCanvas` 保留已有按手势记录的擦除、移动、缩放和内容快照历史。
`MainViewModel.EditPageAppearance` 为手动单页外观修改提供前后版本，窗口通过
`RequestRecordDocumentEdit` 记入当前画布的 `RecordReversibleEdit`，与墨迹、清空等操作交错撤销。
外观恢复重用 `RefreshPageAppearance` 和 `SaveLibrary`，保留自动增长范围。
全局 `TogglePageTheme` 不进入页面历史。物理撤销快捷键的单/双击策略不变，见 workspace-ui.md。

## 离散缩放

Windows/Android `ViewportState` 集中定义 `ZoomStepFactor` / `ZOOM_STEP_FACTOR = 1.05`。
按钮与放大/缩小快捷键在任意当前比例上乘/除该因子，例如 100% → 105%，缩小一步回到 100%。
沿用原中心锚点与 50–6400% 范围；菜单预设独立保留。Android 不能再把加减按钮接到预设列表跳档。
滚轮、连续拖动和双指捏合沿用各自的连续输入策略。

## 验证

- Android JVM：`DocumentEditHistoryTest` 覆盖跨操作顺序、嵌套手势合并、采样次数、无变化保留 redo、
  新编辑分支、页面 reset/clear、容量、恢复回调抑制与恢复失败后的历史保留；`ZoomStepTest` 检查逆操作与范围。
- Windows 原生 WPF：`DocumentHistoryTests` 实际执行橡皮、混合笔迹/文字移动、交错撤销重做与 viewport 保持，
  单页底纹与清空交错、无变化保留 redo、磁盘恢复，以及缩放锚点/范围。
- Android APK/原生测试 APK/lint 构建不等同于真实设备交互验收；不得用 `connectedDebugAndroidTest`
  在用户唯一产品安装上验证历史，见根 AGENTS.md。
