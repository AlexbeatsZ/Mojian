# 旧导入页的纸张与配色兼容

Last verified: 2026-10-29

修改 Notein/OneNote 旧页的显示范围、暗色配色、图片显示或相应导出路径前阅读本文件。
这是一层 Windows/Android 的只读展示兼容，不是笔记库迁移，也不改同步协议。

## 纸张和坐标

- 旧迁移页使用 `page-notein-` / `page-onenote-` ID。普通无界/A4 旧页按连续纸张显示，
  取已存纸张与所有内容边界的并集，内容额外留 6 mm；允许纸张显示原点为负。
- 真实旧页存在 x 约 -2439、y 约 -74 的内容，并非把相同数据重新缩放就能修复。
  扩展的是展示纸张，不平移/缩放笔迹、图片或文字，不修改存储尺寸、viewport 和 revision。
- 普通新建页仍遵循 `(0,0)` 原点和原有 A4 页间距；真实 PDF 固定 MediaBox 不扩展。
- 非 PDF 旧迁移页按连续内容边界分页导出，包含负坐标顶部及最下方内容；真实 PDF 保持原尺寸。
  Android 原点/连续纸张标记仅在展示副本中存在，不进入 canonical appearance。
- Windows 在内容/外观改变时刷新纸张边界缓存，不在每次 pan/zoom 扫描全部笔迹。

## 纸色、笔迹和文字

- 旧迁移页暗色使用默认灰纸 `#1B1B1B`，亮色使用 `#FAFAFA`。旧八位 ARGB 纸色
  （包括 `#FFFFEABD` / `#FF292829`）保留在原始元数据，不能只匹配六位字符串。
- 从原始纸色的相对亮度判断原页明暗，不盲信迁移时统一写入的 `theme=Light`。
  明暗切换时原始中性笔色对应切换，彩色保持色系，必要时提高与灰纸的亮度对比。
  透明度、填充规则、轮廓、图层和对象顺序保持原契约；覆盖纸色的中性笔迹仍作为覆盖色。
- 只适配原始导入 item ID，新插入的图片、新写笔迹不再次套用旧页反色。
- Android 显示笔刷仍保留 SharedStrokeCodec 的原 JSON；富文本使用保存原色的绘制 span，
  snapshot/HTML 序列化仍返回源颜色。切主题不得把显示白色写回原始黑色文字。

## 图片不能只做 RGB 取反

- 真实旧页有蓝底图片同时包含黑色公式与白字。整图 RGB 取反会产生黄底白字，依然难读。
- 需要转换明暗的旧图先采样至约 16384 像素，用 5-bit RGB 直方图识别占比至少 30% 的
  主底色；与主底色 RGB 距离不超过 45 的像素映射到目标纸色，其他文字/彩色像素分别适配。
  黑公式和白字均应保留可见，彩色批注不直接变成补色，源 alpha 不变。
- 没有显著纯色背景时保留原图，避免把普通照片一律变成负片。这是可撤回的启发式展示，
  不是 OCR 或无损语义分割；不能声称所有扫描图/照片均已自动修复。
- 原始图片/PDF 文件不改写，显示派生图按主题独立缓存；Android 沿用 24 MiB LRU。
  自动适配旧图的菜单使用「保留原图」，可返回源图；其他图片保留原有「反色」。打印选择使用有效状态，
  默认恢复原图。新插图继续使用原来的手动反色与导入选项。
- 普通图片/矢量输出沿用展示，打印另外转换灰纸/覆盖色/中性白墨。固定 PDF 原生渲染
  仍使用既有页面反色路径，PDF 原始资源与尺寸不变。

## 验证边界

- Windows 测试覆盖负坐标/四向溢出、普通页/PDF 隔离、原数据不变、八位颜色、原图勾选、
  灰纸和黑/白源墨实际像素。可通过 `MOJIAN_IMPORTED_PAGE_JSON` / `MOJIAN_IMPORTED_PREVIEW`
  对显式选定的真实页做只读渲染，不启动或改写真实笔记库。
- Android JVM 测试覆盖几何、调色、蓝底黑/白字和 canonical 纸色往返；新增 native bitmap /
  富文本 HTML 颜色保留 instrumentation 已编译，不因 APK 构建通过而声称实机执行。
- 两端状态提示外层右/下间距为 0，内侧文字 padding 保留；Windows 真窗口测试测量贴边。
