# 笔触配置与命名预设

Last verified: 2026-11-07

修改笔触预设、配置窗口、曲线和新笔画的风格快照前阅读本文；原有 v1/v2 的校准、输入与
历史兼容规则仍见 `handwriting-engine.md`、`stored-ink-appearance.md`。

## 交互和所有权

- 钢笔浮层的颜色行最右侧是独立的「配置」按钮；另起一行的「预设」下拉框只选择已经保存
  的预设，不含新建、另存或编辑命令。颜色、名义笔宽继续属于当前工具。
- 「配置」打开独立原生窗口，可以选择已有预设编辑，也可以新建并命名。保存修改保持原
  ID；新建生成新 ID。空白、超过 40 字符和已有同名名称须拒绝，不能悄悄覆盖其他预设。
- 窗口使用独立草稿；更改曲线或切换编辑目标不立即修改工具和已保存的预设，取消不产生
  写入。保存已有预设后，所有引用它的笔在下一笔使用更新后的参数；保存新预设后，当前笔
  使用新预设，其他笔维持原选择。已保存的内置预设同样允许编辑，设备本地保存覆盖值。
- 压感、速度、方向、起收尖和稳定性集中在配置窗口；主浮层保留笔宽，避免存在两组相互
  覆盖的曲线/百分比参数。预设库和工具选择随现有 `ToolShelf` 设备本地设置持久化，不新增
  单独的文件写入、同步或服务生命周期。
- 无预设字段的旧工具保持原参数和原 authoring 路径；将其参数以曲线形式登记为已有预设，
  不将它静默重置为工厂值。原参数不符合工厂预设时提供「某色笔（原设置）」。

## 统一参数

- 压力和速度到宽度分别是开关和可编辑折线；横轴是 0–1 压力或 0–64 cm/s 的实际屏幕
  速度，纵轴是名义笔宽的 0–300%。支持非单调和恒定曲线，最多 33 点；端点 X 固定，
  中间点可添加、拖动和删除，输入区间外使用端点值。
- 方向开关和增粗量保留既有向下笔画响应。起笔与收笔分别有开关、文档毫米长度和尖端宽度
  比例；长度不随页面缩放改变。短笔画中两端响应相乘，不产生负宽度。
- 稳定性独立控制位置/压力的时间窗口，沿用 0–100% 映射。高级项提供倾角到宽度、转弯
  增粗和压力/速度/方向的独立响应平滑。倾角 0–60° 线性映射，缺少倾角时保持中性。
- 各宽度响应相乘；关闭某一项使其乘数为 1。位置平滑先于速度、方向和转弯响应，预测和
  wet/dry 交接继续由平台现有输入/渲染路径负责，不存入用户风格控制。
- `shared/pen-style-presets.json` 是两端内置参数的同一来源：自然钢笔采用 v2 的校准曲线且
  关闭自动收尖；经典钢笔组合旧 Android 的压力范围、较弱速度响应、起收尖和转弯增粗；
  均匀圆笔关闭动态宽度。经典是可编辑的风格预设，并不声称重放所有历史 Windows/Android
  v1 的相同像素；历史 Windows 的采样索引收尖和平滑算法仍由原 reader 保留。

## 持久化与平台边界

- 配置后的新笔画使用 `pen-style-v1`，携带完整 `penStyle` 参数快照和现有规范填充轮廓。
  完成后的显示、导出、擦除和跨端移动/缩放都使用该轮廓；不依赖另一个设备是否保存同名
  预设。删除/改名/修改设备预设不能改变已写笔画。历史 `fountain-v1`、`fountain-v2`、
  `shape-v1` 和导入轮廓仍使用原渲染器，不批量重写历史记录。
- Windows 复用 v2 的时间建模、物理速度、几何生成、保留式 Visual 和快照队列，只为新
  profile 解释参数；工具、草稿、正在书写的笔画和后台保存各持有独立的可变参数集合。
- Android 仍固定 Ink 1.0.0，将模型编译为原有 BrushBehavior 图。恒定 1 曲线直接省略，
  其他恒定曲线显式建模，避免 Ink 拒绝相同 modifier 端点。异步笔画完成通过自包含的 family
  ID 传递当时快照，不新增无法释放的全局 brush 注册表。毫米换算必须使用 Android 文档
  单位 `DOCUMENT_UNITS_PER_MM`，不能使用 Windows 的 96 DPI 单位。
- Android 新记录保留可用的原始 `tiltRadians`、`orientationRadians` 和物理单位；Windows
  点模型、复制和快照均透传这些可选字段。Windows 原有 TiltX/Y 仍为角度，重放宽度优先使用
  明确保存的总倾角，缺失时从两轴角度求总倾角。点笔补样也须保留倾角。

## 验证

- 两端模型测试覆盖共有预设、曲线、旧工具迁移、新建/修改/重启恢复、重名拒绝和快照隔离。
- Windows 原生回归覆盖配置窗口的新建/修改/取消、真实工具浮层的独立按钮和下拉框、设置
  恢复、实际宽度/收尖/倾角变化，以及保存轮廓和复制。UI 截图仅使用隔离的临时笔记库。
- Android 原生 fixture 覆盖 preset/恒定/非单调曲线编译、family 快照和规范编码；只编译
  instrumentation APK 不等于已在平板执行或完成物理手写验收。
