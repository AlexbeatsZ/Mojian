# 图形工具与停笔转直线

Last verified: 2026-10-07

修改图形生成、停笔识别、工具参数、原生图形持久化前必须阅读本文，并同时遵守
`input-gestures.md`、`handwriting-engine.md` 与 `cross-platform-parity.md`。

## 可观察的 Notein 依据

本次只读检查的平板安装包为 `com.orion.notein` 2.1.11.0 / versionCode 351。
`one_stroke_to_shape_card_tip` 明确描述：简单几何图形绘制后不抬笔，停顿一秒，
不规则图形转为规则图形；`tips_enable_one_stroke_to_shape` 描述画线后按住、不抬笔的识别入口。
资源还提供 `direct_draw_line`、`show_anchor_on_stroke_to_line` 和独立图形设置页。
这些证据支持默认一秒和显式图形工具的交互，不证明底层静止容差、拟合算法或计时常量。
当前包仍使用 Baidu Protect；普通 DEX 与资源扫描没有恢复私有识别状态机。
墨笺采用独立实现，不复制 Notein 业务代码或模型，不访问其活跃笔记数据。

## 产品行为

- 绘图 Ribbon 在添加工具与触控笔抓手之间放置图形工具，使用两端共享矢量图标。
  第一次点击选中，再次点击打开参数。已有全页快捷工具栏配置保持不变，图形可加入其目录。
- 图形有直线、箭头、圆形、椭圆、矩形、三角形、菱形；按下定义起点，拖动实时预览，
  抬起提交一笔。闭合图形由拖动包围盒定义；圆形取两轴较大跨度作为直径。
  所有图形使用固定线宽，保留拐角，支持黑/蓝/红和 0.1–2.0 mm。
- 参数中的「停笔转直线」默认开启；等待时间默认 1000 ms，可选 200–2000 ms，步长 50 ms。
  这两个参数只由必需的 `shape-default` 预设统一拥有，所有钢笔/荧光笔都读取它。
- 钢笔/荧光笔保持原来的自由书写入口。画出开放曲线后不抬笔，在终点附近停留达到等待时间，
  当前笔画替换为起终点之间的直线；继续移动调整终点，抬起提交。
  本次自动识别范围只包含直线。自由手绘圆/矩形不会自动拟合，其正规图形通过显式工具绘制。
- 静止判定使用屏幕空间，位移超出 2.5 DIP / dp 后重置时间；30 ms 定时器保证没有新 MOVE
  事件时也能转换。闭合/明显回折路径通过弦长与路径长度比拒绝，避免圆圈和涂写被拉直。
  这些数值是墨笺的策略，不能称为恢复出的 Notein 参数。
- 压力橡皮候选优先于停笔转直线。第二指导航、取消、工具/页面切换、失焦或暂停取消未提交图形
  和计时器，不留下半笔或额外 Undo。显式图形不触发压力橡皮。

## 输入与存储边界

显式选中图形时，触控笔、主鼠标拖动和单指拖动均创建图形，这是普通直接内容操作的明确例外。
右键菜单/临时套索、中键导航、双指页面导航保持原契约；第二指取消尚未提交的图形。
回到钢笔、套索或抓手后，单指和主鼠标恢复直接内容操作。

图形存为可编辑笔画 `brushProfile=shape-v1`，不是图片或页面背景；沿用整笔擦除、套索、
混合选择、移动/缩放、Undo/Redo 和导出。Windows 直接画点列，避免自由笔的平滑破坏拐角。
Android 使用公开 AndroidX Ink 1.0.0 的固定线宽原生 BrushFamily 和 naive input model，
每次手势复用一个 BrushFamily，避免每个 MOVE 构建原生笔刷。

页 JSON 与 `.mjn` 的图形点使用 Windows 96 DPI 文档坐标，Android 在其原生单位与这些点之间
显式换算。`kind`、`color` 按现有 Windows 数字枚举序列化；移动和缩放后的当前线宽参与保存。
Android 页模型保留不认识的笔画记录，只重建自己的 `shape-v1`；普通 Android 自由笔原有会话
存储边界不在本次扩大。图形保存、复制与导出复用页面仓库，不改动用户的其他内容。

## 验证

- 两端单测覆盖计时边界、无 MOVE 计时、抖动、移动重置、取消、闭合路径拒绝、反向拖动、
  圆/矩形几何，以及旧预设升级和参数重启恢复。
- Windows 实际 WPF 画布覆盖生成、停笔替换、撤销重做、存储恢复和第二指取消；隔离真实窗口
  检查中文图形菜单和等待时间控件，并渲染截图。
- Android instrumentation APK 可构建，但本平板拒绝安装独立测试包，不能报告 instrumentation 通过。
  Debug-only `ShapeProbeActivity` 只使用独立 DryInkView 和应用缓存，不读取用户页面或设置。
  实机七种图形的原生渲染、点/ID/线宽恢复、移动、缩放、擦除、Undo/Redo 已通过并检查输出图像。
  该 Activity 不进入 Release manifest。
- 物理触控笔的停笔手感、充电噪声与压力橡皮优先级仍需用户实测；自动探针不代表这项验收。
