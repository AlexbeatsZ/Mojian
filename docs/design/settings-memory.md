# 页面与打印偏好记忆

Last verified: 2026-10-28

修改全局主题、新建背景、单页背景入口或打印选项恢复前阅读本文件。
Windows 与 Android 使用相同的行为契约，偏好保存在设备本地，不依赖当前笔记本。

## 暗色模式

- 视图工具栏与「文件 → 选项」中的暗色模式是同一个全局开关。所有已有页面、
  新建页面、导入页面和分屏页面均按这个开关显示，切换文件或重启后保持。
- Windows 保存到 `AppPreferences.PageTheme`，Android 保存到 SharedPreferences 的
  `appearance-preferences`。首次升级从当前页面的旧主题初始化；已有偏好优先。
- 使用有效外观副本覆盖旧页面的主题，不批量改写笔记库中的主题字段。
  页面原有的彩色纸张仍保留色系；Windows 映射已知明暗色卡，未知自定义颜色保留。
  逻辑黑色笔迹与默认文字继续按原有渲染器映射；不修改正文或图像的持久反色标记。
- 普通 PDF/图片导出沿用当前显示主题；打印仍按 OutputAppearance 转换深色纸张和笔迹。
  可编辑包保留原始页面数据。Android 非活动分屏原先是屏幕快照，主题切换后使用已有
  offscreen renderer 重建，过期结果不得盖住已经切换的页面或较新的主题。
- Windows 有效外观是副本，纸张自动增长事件须将页数和无界尺寸同步回原始元数据，
  不可因主题展示分离而丢失 A4/无界纸张的单调增长。

## 默认背景与单页背景

- 「文件 → 选项 → 绘图与页面 → 默认页面背景」选择以后新建普通页面的底纹。
  初次升级沿用最后一次成功创建页面的底纹，以后独立保存。
- 绘图/视图中的背景格式菜单只改当前页；菜单底部的「设置默认页面背景…」直接
  打开选项并定位这一行。Android 默认值选择器自身不再包含递归跳转入口。
- 新建页面弹窗每次从默认底纹开始。用户临时改某一页或某一次创建的底纹不会更改默认值。
  纸张类型和纸张颜色仍沿用上次成功创建的选择；取消弹窗不更改已记忆模板。
- Windows 新建笔记本内自动创建的普通页也使用默认值。PDF 导入保留空白底纹和原始尺寸。
  默认背景不会追溯修改已有页面，也不覆盖复制/导入页面的原有底纹。

## 打印窗口

- 只在打印界面自动恢复上次选择，不新增任何「默认打印设置」面板。
- 记住范围、纸张、方向、边距、是否省略 A4 尾部空白、隐藏背景格式和输出页码。
  修改时保存，即使没有真正发起打印也能在下次打开或重启后恢复。
- Windows 保存到 `AppPreferences.LastPrintOptions`；Android 使用 `last-print-options`。
  无记录或不支持的枚举/边距回退到原有初始值。打印和普通导出选项互不覆盖。
- 图片反色勾选与当前内容相关，不跨文件套用旧图片 ID。重新打开窗口时仍从图片的
  当前显示状态生成勾选；页码若超出新文档范围，由已有分页校验提示，允许用户修改。
- 系统打印机、驱动属性、份数等由操作系统原生打印窗口管理；此处保存墨笺自身的选项。

## 验证边界

Windows 回归覆盖真实背景菜单跳转、默认值控件、打印控件改变、窗口重开与磁盘恢复，
以及跨页/分屏/跨库主题和新建默认值、纸张增长。Android JVM 测试覆盖偏好迁移、损坏值、
往返和一次性覆盖；APK、native-test APK、lint 属于编译层证据。Android 实机交互和
实际打印机输出须单独验收，不能以编译或 Windows UI 测试替代。
