# 墨笺输入设备与交互契约

Last verified: 2026-10-12

修改 Android / Windows 的指针分发、对象选择、文本框、画布变换、触控笔工具、快捷键或压力橡皮前，必须先读本文。
本文是输入行为的唯一设计来源；`workspace-ui.md` 与 `windows-desktop.md` 只能引用，不能另行定义冲突手势。

## 1. 不可破坏的总原则

软件同时支持触控笔、手指和鼠标，但三类设备不共享全局工具模式：

- 触控笔是工具型输入，拥有自己的 Ink / Lasso / Hand 状态；钢笔、荧光笔和橡皮属于 Ink 工具族的具体预设。
- 手指是直接内容操作加页面导航：单指操作内容，双指操作 Viewport。
- 鼠标是桌面式直接内容操作加页面导航：左键操作内容，静止右键打开菜单，按住右键拖动临时套索，中键/滚轮操作 Viewport。

选择触控笔套索或抓手时，只改变触控笔。手指仍执行单指点击/框选与双指页面导航，鼠标仍执行左键直接操作与中键/滚轮导航。代码中的历史字段 `singleFingerPanEnabled` 目前仅表示“触控笔抓手”，不得再用它改变手指或鼠标。

显式选中「图形」是有意的创作例外：主鼠标、单指和笔拖动都创建当前正规图形；第二指优先取消未提交图形并导航页面。返回其他工具后恢复普通直接内容契约。钢笔/荧光笔的停笔转直线只处理真实笔，不改变普通单指或鼠标。图形类型、计时、取消与存储详见 `shapes-and-straightening.md`。

没有“整个软件进入套索模式”或“整个软件进入光标模式”的概念。光标/插入文本框模式已经删除；文本创建是手指和鼠标空白单击的固有行为。

## 2. 内容状态

普通对象至少有未选中、已选中两态。文本框有未选中、已选中、编辑三态。

空白单击产生的文本框先处于未提交临时态：

- 立即显示 caret，但 Android 不主动弹出软键盘；
- 第二次单击该已选文本框后进入正式编辑，Android 才请求软键盘；
- 鼠标进入编辑时是否出现软键盘由硬件键盘和系统 IME 策略决定，应用不强制；
- 第一个非空白有效字符出现后才提交进文档/快照；
- 未输入有效内容便失焦、点击其他内容、开始框选、切换操作或开始页面导航时自动删除；
- 未提交临时文本不持久化、不扩展页面，也不产生 Undo；输入后又清空并放弃时净结果同样不保留无意义 Undo。
- 临时文本为空或仅含空白时不绘制混合选择框；首个有效字符出现后才允许选择框随文本几何显示。

## 3. 手指

### 单指点击

- 未选中普通对象：选中。
- 已选中普通对象：保持选中，不激活第二种功能。
- 未选中文本框：第一次点击只选中。
- 已选中文本框：再次点击进入编辑、放置 caret 并请求 Android 软键盘。
- 编辑中的文本：交给原生文本组件移动 caret、选择文字和处理输入法。
- 空白：创建未提交临时文本框，不立即请求 Android 软键盘。

这是严格的 `Select -> Edit` 两阶段文本模型。不得用双击检测器代替两次普通点击。

### 单指拖动

- 起点命中当前已选内容或选择框控制柄：越过平台 slop 后移动/缩放当前选择。
- 控制柄采用触摸最大 24 dp、鼠标最大 12 px/dp 命中半径；内容内部的命中侵入量每轴最多占尺寸的四分之一，中央至少一半宽高保留为移动区并优先于控制柄。小图和狭长图片的中心不能因手柄重叠变成缩放。
- 四角沿起始对角线投影拖动，固定对角、保持起始宽高比；四边中点只改变对应轴。以按下位置到当前位置的位移作用于起始内容手柄，不能吸附到按下点或带 padding 的显示框。最小尺寸在公共选框统一限制，并以起始短边封顶，避免小图尺寸跳变或逐对象限制导致变形。
- 其他任何起点：越过平台 slop 后开始矩形框选。

因此未选中的图片、文本、表格或其他对象不能“一拖就移动”；在它们表面起拖仍是框选。移动必须先点击选中，再从已选内容上拖动。多选框内部的空白间隙不算“已选内容命中”，从间隙起拖仍应框选。

### 框选

矩形框选不要求从空白开始，默认采用完全包含选择：

- 文本框、图片、表格、标签和其他矩形对象的完整选择几何必须在框内；
- 自由笔迹尽量检查所有 stroke 输入点/实际几何都在框内，不能用过度膨胀的包围盒，也不能“任一点相交即选中”；
- 位于大图片上方的小对象可被完整框住，而只被部分覆盖的大图片不应同时选中。

触控笔 Lasso 完成后的对象判定也使用完全包含语义；区别只在于它画自由路径或触控笔预设的矩形路径。

### 双指

双指永远操作页面，不操作对象。无论起点在空白、图片、文本、已选对象、控制柄还是笔迹上：

- 双指拖动平移整个 Canvas / Viewport；
- 捏合缩放页面；
- 默认不定义双指旋转。

第二根手指加入时，画布父层必须抢占完整事件流，取消尚未完成的单指框选、移动或缩放候选，丢弃未提交空文本，再进入同一套双指变换仲裁。双指序列中途抬起一指后，剩余一指在本序列结束前也不能突然变回内容拖动。

Android 的双指判断必须先于鼠标右键和小米笔套索快捷键；开始导航时关闭现有菜单，并取消已开始的右键菜单/套索候选。
整个双指序列（包括只剩一根手指的阶段）屏蔽右键按下、松开、套索预览和菜单，不得在导航结束后补弹菜单。
鼠标松开或笔悬浮属于独立事件流，不能结束触摸导航，也不能改变它的焦点或缩放状态。只有最后一指抬起、触摸取消或 Activity 暂停才释放双指捕获。
触控笔抓手及鼠标中键页面导航期间也屏蔽右键菜单/套索，导航结束后恢复普通右键行为。

缩放锁只阻止捏合缩放提交，不阻止双指平移；Ribbon 缩放按钮和预设仍可改变缩放。

### 长按与双击

- 非文本编辑态长按对象：选中该对象并打开与鼠标右键相同的上下文菜单。
- 文本编辑态长按：交给系统文本组件处理选词、handles、复制、剪切、粘贴和输入法行为。
- 画布双击当前为 Reserved，不绑定选择、编辑、打开或缩放，也不引入等待双击导致的单击延迟。

## 4. 鼠标

鼠标左键的内容语义与手指单指一致：

- 左键单击未选中对象：选中；单击已选普通对象：保持选中。
- 第一次单击文本框：选中；再次单击已选文本：进入编辑并放置 caret。
- 左键单击空白：创建未提交临时文本框。
- 从已选内容/控制柄起拖：移动/缩放选择。
- 其他左键拖动：矩形框选，且采用完全包含判定。

鼠标右键在未超过系统拖动阈值时等价于触摸长按，菜单改在右键松开时打开。按住鼠标右键并移动超过阈值则改为临时自由套索，松开完成选择且不再打开菜单。文本编辑中的静止右键仍交给原生文本编辑菜单；其他对象使用墨笺深色命令面。

映射为右键的笔侧键不得使用移动距离区分单击和套索，因为笔尖接触抖动会造成随机误判。它只使用按下到松开的时间窗：在 Windows 系统双击时间内松开，一律视为右键单击，移动量不参与判定；悬空单击也应打开与鼠标右键相同的菜单。笔尖接触后立即显示并持续追加套索虚线，不等待时间窗结束；若在时间窗内松开，则丢弃这条预览线并打开菜单，不改变原选择。超过该时间窗仍保持按下，预览线转为可提交的临时自由套索；松开只完成框选，绝不自动打开菜单。笔侧键单击产生的菜单须等本轮驱动补发的兼容鼠标事件排空后再显示，避免刚打开就被后续事件关闭。

Android 同时迁移普通鼠标的完整桌面输入：右键仍按系统拖动阈值区分菜单与临时自由套索，中键拖动平移，`Ctrl + 中键` 拖动缩放。小米笔不伪造 Windows barrel 事件；当某个 `Xiaomi Smart Pen Keyboard` 实体键的“单击”绑定为“套索/菜单（短按/按住）”时，该键改用上述右键式复合语义；为兼容既有设置，旧的“单击切换到套索工具”绑定也自动使用同一行为，并在设置行显示为“套索（短按菜单）”。按下到松开小于 Android 已配置的“按住阈值”时打开菜单，达到阈值时提交套索，绝不检查移动距离。笔尖接触后无论最后会判为菜单还是套索，都必须立刻显示并追加虚线；短按时仅丢弃预览而保留原选择，长按时才提交。普通键盘 PageUp/PageDown 以及未绑定为该复合套索行为的笔键继续走原快捷键状态机。

上下文菜单已经打开时，下一次笔侧键按下必须先关闭该菜单并重新建立上述时间窗；继续按住超过时间窗后可以直接进入套索，菜单不得吞掉这次手势。
上下文菜单已经打开时，中键按下也必须先关闭菜单，再立即进入原有的中键平移或 `Ctrl+中键` 缩放路径。
Windows Ink 驱动可能把笔侧键右键提升成不带 `StylusDevice` 的兼容鼠标事件；实现必须结合 barrel-button 状态和最近的笔悬浮位置判定来源，并在右键序列已建立后同时接受原始笔移动与兼容鼠标移动、按坐标去重。悬浮 `StylusDown` 或已建立的右键序列绝不能进入书写分支。
右键临时套索的生命周期必须绑定“按钮仍按住”，不能只等待兼容 `MouseUp`：原始 `StylusButtonUp`、兼容右键抬起、鼠标/笔捕获丢失、窗口失焦、页面或工具切换都从同一幂等出口结束或取消，并清空 `_isLassoing` 与临时路径。驱动先发 barrel/stylus 事件、后发兼容鼠标事件时，barrel down 必须先占用输入，不能让中间的 `StylusDown` 落入书写。

Viewport 导航固定为：

- 中键拖动：平移页面；
- 普通滚轮：纵向平移；
- `Shift + 滚轮`：横向平移；
- `Ctrl + 滚轮`：以指针为锚缩放，Ctrl 优先于 Shift；
- Windows 的 `Ctrl + 中键拖动`：按固定屏幕对角方向缩放，并保持初始接触点为内容锚；
- `Space + 左键拖动` 可作为临时页面抓手，但普通左键拖动的默认仍是内容框选/移动。

拖动缩放的方向是固定屏幕语义，与画布中心和起点所在象限无关：向右下移动必须放大，向左上移动必须缩小；右上或左下的等量对角分量相互抵消。按住中键后，触控笔始终是实际的导航输入：笔无需落下，保持悬浮并移动就直接平移页面；中键不松时按下 `Ctrl` 就立即切换为对角方向缩放，松开 `Ctrl` 立即回到平移，不得要求重新按中键。中键按下是唯一的触发动作，不得再要求一次笔尖接触或第二次点击。选中 Hand 时的笔缩放亦遵循同一方向规则。笔接触后的高精度事件流只取最新合并采样点，不重放历史点，避免卡顿或方向回跳。

Windows 会为同一次笔移动额外合成一份鼠标兼容事件。去重的对象仅是这份副本，不是触控笔本身。但部分 Windows Ink 驱动只通过该兼容事件持续报告笔的悬浮位置，因此在未落笔的中键导航期间，它既刷新笔尖/插入空间虚线，也作为该悬浮导航的唯一坐标源；笔落下后则切换到笔高精度流，不得同时用两条流重复移动页面。

触控笔 Hand 被选择时，鼠标指针仍是普通箭头，左键仍是内容操作；只有中键/滚轮/Space 进入鼠标页面导航。

## 5. 触控笔

触控笔只遵循自己的工具状态：

- Ink：真实触控笔接触才写入钢笔/荧光笔，或执行所选整笔橡皮；手指和鼠标永不落入 Ink。
- Lasso：触控笔拖动绘制自由/矩形套索，完成后按完全包含规则选择混合内容。
- Hand：触控笔拖动平移 Viewport，不移动对象；选择其他绘图工具后退出，再次点击已选 Hand 打开灵敏度设置。
- 硬件反转橡皮和压力临时橡皮仍是触控笔专属路径。

`插入空白空间` 是用户明确指定的跨设备例外，不是第四种全局笔工具：开启后，单指拖动或触控笔拖动都可推移内容；鼠标左键仍按本契约直接选择/编辑/框选。触控笔和鼠标具有悬浮状态，因此两者悬浮时都显示当前插入位置的虚线预览；手指没有悬浮，只在按下拖动后显示操作线。第二根手指加入仍取消当前插入候选并进入 Viewport 导航。除明确记录的此类命令外，未来辅助命令不得擅自接管其他设备。

Windows 笔迹反馈不得绘制从当前笔尖向预测位置伸出的可见前导线。触控笔悬浮反馈只保留屏幕空间笔尖点；已确认的真实采样才进入可见笔迹。

触控笔开始写、套索或抓手操作时，应丢弃未提交空文本，但不应仅因为切换笔工具就清除手指/鼠标建立的对象选择。钢笔或荧光笔接触已有混合选择的边框内部时直接拖动整个选择，不写入笔画；接触选择外部时清除选择并正常书写。触控笔 Ink 不创建文本。

快捷键允许持久切换与 spring-loaded 临时工具：短按可切换触控笔工具，按住可临时进入目标工具，松开恢复先前工具。具体按键绑定由快捷设置保存，不写死在本契约中。

Spring-loaded 不是画布内部的第二套私有逻辑。压力橡皮、中键或映射成中键的笔侧键开始时，工具栏和指针反馈必须临时显示真实的橡皮或 Hand 状态；结束/取消时恢复先前工具和插入空间状态，且临时状态不写入持久选择。Hand 的移动灵敏度为持久设置，Android 与 Windows 都使用 25–300% 范围，只缩放单笔/中键平移增量，不改变双指页面导航。

## 6. 输入优先级

```text
Touch
第二根手指加入         -> 取消单指候选 / 临时空文本 -> Viewport Pan / Zoom
已在正式文本编辑中     -> 原生文本组件
已选内容或控制柄上拖动 -> Move / Resize Selection
其他单指拖动           -> Rectangle Marquee
单指点击               -> Select / Edit Selected Text / Create Temporary Text
```

```text
Mouse
Middle Drag            -> Viewport Pan
Ctrl + Middle Drag     -> Viewport Radial Zoom (Windows)
Ctrl / Shift / Wheel   -> Viewport Zoom / Horizontal Pan / Vertical Pan
Right Click            -> Context Menu
Left Drag on Selection -> Move / Resize Selection
Other Left Drag        -> Rectangle Marquee
Left Click             -> Select / Edit Selected Text / Create Temporary Text
```

```text
Pen
Pen Tool = Ink         -> Stroke / Highlighter / Eraser
Pen Tool = Lasso       -> Pen Lasso Selection
Pen Tool = Hand        -> Viewport Pan
```

选择框存在且原生文本编辑器未获得焦点时，无修饰键的 `Backspace` 或 `Delete` 固定删除框内全部混合内容。这个行为不依赖当前笔工具，也不允许被工具预设按钮替代；工具详情面板不提供“删除工具”或“删除所选”按钮。

## 7. 跨层实现边界

Android 的 `CanvasInputHost` 必须在 `EditText`、选择层、笔迹层和插入对象层之前观察完整 pointer stream。第二指抢占属于父层，因为子 View 一旦消费第一指的 `DOWN`，后续事件不能靠另一个 sibling 可靠接管。`SelectionOverlayView` 统一实现手指/主鼠标的单指候选、移动/缩放、矩形框选、长按和八控制柄；插入对象层不再单独定义双击选择或一拖即移动。

插入空白空间开启时，Android 父层还必须先接管单指序列，确保手指从文本或对象表面起拖也能执行插入；第二指分支仍排在它之前。选择层只为手指让路，鼠标左键继续走直接内容状态机。Windows 同样只把单指触摸和真实笔送入插入动作，鼠标仅提供悬浮虚线并保留左键直接操作。

Windows 的 `NoteCanvas` 同样在一个直接操作状态机内处理鼠标左键和触摸单指；WPF preview touch boundary负责在文本控件已经消费第一指时仍观察第二指。`DirectInputPolicy` 是两端测试的设备独立决策表，不能重新加入“所选笔工具决定手指/鼠标”的参数。

旧配置里残留的 `draw:cursor` 只作为未知 stale ID 被过滤，不迁移成其他命令，也不在 Ribbon、快捷目录或全页工具栏目录出现。

## 8. 坐标与渲染

完成的笔迹、标签、文本框、插入对象、套索和选择框都使用文档坐标。`ViewportState` 是唯一的文档/视图变换所有者：

- 触摸/鼠标命中在边界处从 view 转 document；
- 移动增量、完整包含判定、控制柄缩放和持久化在 document space 完成；
- AndroidX Ink 的 wet/dry transform 必须保持一致；
- 缩放锚是双指 centroid 或鼠标指针，而不是任意固定屏幕点；
- 触控笔书写期间不得改变 Viewport。

Windows 与 Android 的缩放范围统一为 50–6400%（0.5–64 倍）。预设保留原有档位并增加 1600%、3200%、6400%；菜单、按钮、滚轮、拖动和捏合缩放都使用 `ViewportState` 的同一范围，视图恢复也不得截回旧的 800% 上限。到达上限后双指仍可平移并立即缩小，锚点保持规则不变。范围和预设由各端 `ViewportState` 集中定义，Android 的快捷动作目录复用同一预设。这是墨笺产品范围，不是对 Notein 私有运行时的推断。

## 9. Xiaomi 触控笔快捷键

实机证明 `NVTCapacitivePen` 提供位置/压力/倾角，`Xiaomi Smart Pen Keyboard` 以 PageUp/PageDown 键盘事件提供两个实体快捷键。只在设备名完全等于 `Xiaomi Smart Pen Keyboard` 时拦截，普通键盘 PageUp/PageDown 必须保持原义。

每个实体键独立支持单击、急促双击和按住；双击窗口 150–600 ms，按住阈值 200–1200 ms，由用户设置。这里的“双击”是实体快捷键时序，不是画布双击手势。单击若需等待双击判定，只能延迟快捷键动作，不能延迟画布单击。

## 10. 压力临时橡皮

1. 开关、阈值、dwell、触发路程上限和半径只属于指定的整笔橡皮预设；钢笔/荧光笔面板不得复制这些参数，也不得用固定半径实现旁路。路程上限默认 1 mm，可调 0.1–10 mm，步长 0.1 mm；旧预设缺失该字段时补默认值。
2. 所有钢笔和荧光笔都可触发该橡皮；Lasso、Hand、显式橡皮操作和非触控笔输入不得触发。
3. 完成一笔并抬起后才允许压力橡皮候选。后续接触不要求 `down` 瞬间就超过阈值；接触过程中压力首次升到显示阈值时才开始候选。之后需在小屏幕半径内停留可调 dwell；移动超出半径重置计时，压力降低则取消当前候选。压力候选优先于停笔转直线，显式图形不触发压力橡皮。
4. 激活时取消临时 wet stroke，spring-load 指定橡皮工具，并在当前位置按该预设半径立即执行一次整笔擦除；工具栏选择态和橡皮圆必须同步改变，不得要求用户再移动一次才生效。
5. 抬笔或取消无条件恢复原书写工具并清除可见橡皮圈。橡皮半径的跨端范围为 0.25–40 mm。
6. 每次钢笔/荧光笔落笔时捕获指定橡皮的路程上限，从 DOWN 开始累计真实输入轨迹的线段长度，包括低压力阶段和合并的历史点，不包含预测点。单位按现有文档毫米转换，与笔宽/橡皮大小一致；在 800% 缩放时，同一文档轨迹仍计相同路程。
7. 累计路程严格大于上限后，取消等待中的压力候选并锁定「本次接触不再压感切换」，即使回到起点、停住、压力升高/降低或重新进入 dwell 也不能解除。只有抬笔、取消、工具或页面切换重置；这与静止计时超出 slop 后重新开始是两个独立状态。
8. 该路程约束只限制激活前的压感切换；已经激活的临时橡皮和手动选中的橡皮可以正常拖动擦除。距离锁定后不再用高压力候选阻挡停笔转直线。

Notein 资源只证明默认开启 hold-to-erase 和可见默认灵敏度 20%，没有证明 20% 到标准化压力的映射或精确 dwell/slop。墨笺参数必须继续明确可调，不得称为恢复出的 Notein 常量。

## 11. 验证要求

自动测试至少覆盖：

- 笔工具状态不参与手指/鼠标 direct-pointer 决策；
- 第二指在任何命中目标上都得到 Viewport 优先权；
- Android 双指抢占右键/小米键候选；残余单指、鼠标释放和笔悬浮保持捕获，最后一指抬起/取消/暂停后才能恢复，松键不得补弹菜单；
- 只有已选内容可拖动，其他起点进入矩形框选；
- 小图/狭长图在 50–6400% 和触摸/鼠标命中半径下保留中心移动区，八柄仍可命中；四角保持比例/对角锚点且越过锚点不翻转，边柄只改变一个轴；柄附近按下不跳变，反向原路拖动恢复起始几何；
- 完整包含选择拒绝仅部分覆盖的大对象，边界上的完整对象仍可选；
- 临时空文本不进入快照/持久化/Undo，首个有效字符提交，失焦或页面导航删除；
- 文本严格 Select -> Edit，不存在画布双击动作；
- 鼠标中键/滚轮与触控笔 Hand 互不污染；
- 对角拖动向右下放大、向左上缩小，不依赖画布中心；触控笔侧键中键导航只消费最新笔点且不重复消费提升鼠标流；
- 鼠标右键以系统拖动阈值区分单击/套索；笔侧键只以按下到松开的系统时间窗区分，绝不使用移动距离，二者松开后的菜单/框选结果必须互斥；
- Android 鼠标右键/中键与 Windows 保持相同入口；小米“单击绑定为套索”的实体键使用 Android 配置的按住阈值完成短按菜单/长按套索，接触后的预览线不等待阈值；
- 右键套索在任一释放/捕获丢失/失焦路径后立即清空临时虚线，之后的无按钮悬浮移动不得继续套索或落笔；
- 压感橡皮由橡皮预设唯一控制，钢笔/荧光笔可触发而 Lasso/Hand 不可触发；激活和恢复期间工具栏状态与实际擦除半径一致；
- Hand 灵敏度只作用于单笔/中键平移，spring-loaded 状态结束后恢复原工具；
- `Backspace` / `Delete` 在非文本编辑态删除当前混合选择；
- 触控笔 Lasso/Ink/Hand 不改变手指和鼠标语义；
- 插入空白空间允许单指/笔拖动、笔/鼠标悬浮预览，但鼠标左键仍是直接内容操作；
- 双指变换 slop、pan-to-pinch promotion、缩放锁和指针重排无跳变。

真实设备验收仍需覆盖 Android 软键盘首次不弹、第二次点击弹出、编辑态系统长按、在大型图片表面框选小对象、第二指中断单指框选，以及触控笔 Ink/Lasso/Hand 与手指/鼠标并行互不串模式。
