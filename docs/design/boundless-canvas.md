# 无限画布与 PDF 智能裁剪

Last verified: 2026-10-02

修改无界页面的尺寸、自动拓展、底纹绘制或 PDF 裁剪前，先阅读本文件。
本契约同时适用于 Windows `PaperKind.Infinite` 与 Android `PaperSize.BOUNDLESS`。
底纹参数与坐标换算遵循 `docs/design/page-backgrounds.md`，不得以设备 density 决定间距或点半径。

## 页面范围

- 左上角固定在文档坐标 `(0, 0)`，纸张只能向右、向下拓展。
- 新页初始纸张为 210 × 297 mm 连续矩形，没有 A4 分页或页间距。
- 任意实际内容都能触发：完成的笔画、非空文字、标签、图片、贴纸、表格、附件、链接等对象。
- 完整内容边界距右边或下边不超过 24 mm 时，对应方向按 100 mm 步长增加，直到余量大于 24 mm。两轴独立计算。
- 完成书写、增加/移动/缩放内容、插入空间及恢复旧页时检查。取消的 wet stroke、套索预览、橡皮光标、悬浮点和临时空文本不计入。
- 平移、滚轮、Hand、中键、缩放、窗口/分屏尺寸及全页切换不触发拓展；判定不使用 viewport 边界。
- 完全位于原点左侧或上方的内容不触发拓展。已有溢出内容仍可见、可编辑、可导出，不移动或裁掉。
- 已存宽高只增不减；删除、擦除、撤销、移回内部、重开和切换纸张类型不自动缩小。
- 纸张颜色和底纹限制在实际纸张范围，范围外使用工作区颜色；内容层不按纸张边界裁剪。
- A4 保持原有内容/视图触发分页策略；PDF 原始页面保留固定 MediaBox。

## 保存与兼容

Windows `PageAppearance.InfiniteWidth/InfiniteHeight` 与 A4/PDF 的 `Width/Height` 独立，以 96 DPI 文档单位保存。
Android `PageViewSettings.boundlessDocumentWidth/boundlessDocumentHeight` 与 PDF 自定义尺寸独立，以 `DOCUMENT_UNITS_PER_MM` 文档单位保存。
旧页缺少新字段时从初始矩形开始，打开后根据已有内容向右下补足，不改变内容坐标。

`.mjn` 的 `viewSettings` 使用 Android 的同名字段；Windows 按物理毫米换算，不直接复制桌面 DIP。
新页模板不继承旧无限页已经增长的宽高。交互检查使用缓存笔画边界，不重新扫描密集页的所有采样点。
视图移动仍不得引发完整页面序列化。

## 内容边界与分页导出

无限页导出范围与保存的画布范围独立：

1. 合并导出时仍存在的笔画、非空文字、标签和插入对象边界。
2. 默认按 A4 分页；纸张、方向和物理边距由导出设置选择。不强制包含原点、已删除内容或历史拓展出来的空白。
3. 三个 PDF 图层共用同一个裁剪原点、尺寸和缩放，不受当前平移、缩放、窗口或分屏影响。
4. 裁剪不修改页面宽高。删除远处内容后 PDF 可变紧凑，画布仍保留历史最大尺寸。
5. 空页输出一张所选纸张；原始 PDF 在自动纸张模式保留源 MediaBox；A4 连续纸张逐页输出。

宽内容按纸张可用宽度等比缩小，窄内容不放大，长内容向下切成独立物理页面。
导出、打印、页数预览和输出页码共用 `docs/design/export-and-print.md` 的分页计划。

导出保留当前纸色、笔迹、图片反色状态及 PDF 图层语义；打印单独执行暗色页白墨转黑、黑纸转白、图片反色选择，以及可选的隐藏底纹。参见 `insert-and-export.md`。无限页自动页面标题不参与内容裁剪或导出，工具光标、选择框和编辑光标也不进入导出。

## 验证

两端覆盖阈值边界、横纵独立增长、各内容类型、左/上溢出、删除后不缩小、尺寸保存/交换、视图不增长及删除后裁剪变小。
Windows 用真实 WPF Canvas 插入/删除对象、切换 viewport 并渲染导出图层，验证交互路由和裁剪尺寸。
