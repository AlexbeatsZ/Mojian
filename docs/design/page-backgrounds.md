# 跨端页面背景

Last verified: 2026-10-19

修改纸张底纹、背景菜单、间距、页间空隙或对应导出/打印前阅读本文件。
Windows 与 Android 共用 `shared/page-backgrounds.json`。Windows 将同一个文件嵌入程序集，
Android 将其打包为 Java resource；不要在 renderer 内另写一套尺寸或颜色。

## 坐标与间距

JSON 中所有长度均为共享笔记格式的 96 DPI 文档单位，1 单位 = 25.4 / 96 mm。
Android 在绘制边界乘 `DOCUMENT_UNITS_PER_MM * 25.4 / 96` 转为自己的书写坐标。
禁止乘设备 density；viewport 再统一变换纸张、背景和笔迹。菜单名称也来自同一个文件。

| 底纹 | 共享文档间距 | 物理间距 |
| --- | ---: | ---: |
| 标准横线、纯横线、标准双栏、标准方格/点阵 | 32 | 8.4667 mm |
| 窄横线、窄双栏 | 24 | 6.35 mm |
| 宽横线、宽双栏 | 43.2 | 11.43 mm |
| 密集方格/点阵 | 16 | 4.2333 mm |
| 宽距方格/点阵 | 48 | 12.7 mm |

标准 32 保持现有 Windows 标准底纹密度；其余采用原 Android 的分类比例：横线
0.75 / 1 / 1.35，方格和点阵 0.5 / 1 / 1.5。旧代码的 Windows 24/32/48 分类和
Android `28 * density` 不是可互换的物理尺寸，现已移除。

- 普通/强调线宽都为 0.8，每四行/列使用强调色；编号来自原点和整数格号，避免浮点累加改变强调线位置。
- 点阵半径 1.25；横线边线在 x=64，宽 1.2；纯横线不画边线。
- 双栏中线用强调色、普通线宽，位于实际纸宽的 1/2，与 viewport/裁剪无关。
- 无界纸张增长后 Android 背景层要同步当前纸张设置，不能继续使用旧快照的中线坐标。
- 明暗主题各有一套普通线、强调线、点阵和边线颜色，来自 JSON。
- 所有底纹均锚定文档原点，不随平移、裁剪、导出或分屏重置。每张纸分别裁剪，纸外及 A4 页间不画底纹。
- A4 页间空隙统一为 32 个共享单位；Android 之前的 12 mm 已移除。
  Android 纸面、底纹、增长和导出均使用保存的纸张宽高，而非覆盖为默认 A4 尺寸。

## 保存、输出与兼容

背景是绘制策略，不能写入笔迹或移动旧内容。已存背景枚举、数值和 `.mjn` 名称不变，
无需重写页面；更新两端后按同一策略重绘。旧版客户端继续使用旧底纹，必须更新双方才能对齐。
统一 A4 页间空隙会改变 Android 旧版第二张及后续纸面的显示位置，但不修改已有内容坐标，
使其与共享格式及 Windows 的位置一致。

屏幕和普通导出使用页面当前主题；暗色页打印使用浅色底纹配色，以适应黑纸转白。
`隐藏背景格式` 仅在打印时跳过全部横线、边线、中线、方格和点阵，不改页面设置。
背景仍在插入内容下方。图像/PDF 背景、页面颜色、笔迹和对象不属于这份底纹定义。

## 验证

- Windows `BackgroundPatternTests` 实际渲染 14 种格式 × 两种主题，检查文档位置、
  viewport 独立、裁剪和隐藏打印底纹，输出到临时目录 `.agents/mojian-background-parity`。
- `TwoColumnBackgroundTests` 保留菜单、存储/交换、中线与 A4 空隙检查。
- Android `BackgroundPatternTest` 覆盖共享单位、稳定枚举、保存往返、边线与分类比例。
- Android `BackgroundPatternIntegrationTest` 对 160/320/480 density 的 native Canvas 逐像素比较，
  并比较 live/output 背景、viewport 独立和打印隐藏。仅构建测试 APK 不代表设备执行。
